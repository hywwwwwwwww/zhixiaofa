## 3. 修改密码页「小眼睛」错位（两套同特异性规则打架）

用户截图：个人中心 → 修改密码，三个密码框的眼睛都偏上、贴到输入框上沿。

**根因**：`.zf-pwd-toggle` 有**两套同特异性定义**：
- 登录页那套（文件上方）：`top:50%; transform:translateY(-50%)`；
- 个人中心/密钥框那套（文件下方，后声明）：`top:27px`（相对整个 .zf-field），但**没写 transform**。
同特异性下逐条属性比较：`top` 取后者的 27px，而 `transform` 只有前者有 → 眼睛在 27px 基础上
再被抬高半个自身高度，正好错位半个图标。**这是「同特异性后声明者胜」的又一例**。

**修法（统一组件，不打补丁）**：所有密码框改用登录页的 `.zf-pwd-wrap` 包裹结构——
- profile.html 3 处、admin/ai-settings.html 1 处：input + button 包进 `.zf-pwd-wrap`，去掉 `zf-field--pwd`；
- app.css 删除旧 `.zf-field--pwd` + 第二套 `.zf-pwd-toggle`（保留密码强度条样式，注释留档）；
- 现在全站只有一套 toggle 定位：`right:5px; top:50%; translateY(-50%)`。

**验证**：三个密码框实测 `dy=0`（眼睛中心与输入框中心零偏差）、`eyeRight=5`、`inside=true`；
截图 412。版本号 20261021c，static-check 全绿（花括号 921/921）。
备份 `workspace/backup-pwd-toggle/`。

## 4. ★管理端全站失效：一个裸 CTX 让整套外壳没渲染

用户截图：管理端数据看板所有指标显示「-」、趋势/分布图全空、连侧栏都没有。

**根因**：上一轮给侧栏图标写 `<img src="' + CTX + '/favicon.svg...">`，
但 **`CTX` 只是 common.js IIFE 内的私有变量，对外只暴露 `ZF.CTX`**；
admin-common.js 里没有 `CTX` → `renderAdminSidebar` 抛 `ReferenceError`。
更糟的是它跑在 `initAdminPage()` 的 `.then()` 里，**promise 链把异常吞了**：
控制台无报错、`window.onerror` 也不触发，页面停在「什么都没渲染」的状态
（侧栏/顶栏/统计卡/图表全部缺席）。这正是用户看到的画面。

**修法**：admin-common.js 改用 `ZF.CTX`（common.js 内部仍可用裸 CTX，作用域内合法）。
修完实测：侧栏 10 项、markImg=true、canvas=7、11 个指标卡数值正常（截图 413）。

**顺带修**（回归暴露的数据型问题，非本次改动）：用户管理「联系方式」列，
10 位 QQ 邮箱（3529262973@qq.com）折成 3 行 → 行高 60→80，破坏表格节奏。
改为单行省略 + title 悬停看全值（`.zf-user-contact__line`）。

**验证**：`verify-admin-ui.js` **148/148**、`verify-admin-real.js` 10/10。版本号 20261021e。

★教训（已记入 MEMORY-dev）：
1. **`ZF.CTX` 是唯一公开的上下文前缀**；跨文件引用一律 `ZF.CTX`，不要写裸 `CTX`。
2. **promise 链会吞异常**：页面「全空 + 控制台干净」时，先查 DOM 关键节点是否存在
   （sidebar / nav 数量 / canvas 数量），再顺链找人。
3. **改公共 JS 后必须跑 `verify-admin-ui.js`**——它会逐页断言外壳与表格，
   这类「静默全灭」只有 DOM 断言能抓住；我上一轮只做了 node --check（语法通过≠运行正确）。
